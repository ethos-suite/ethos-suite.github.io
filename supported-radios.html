Which radios run FrSky ETHOS? FrSky's FAQ names the TANDEM and TWIN series and the Horus X10 and X12 with ISRM. Release notes name more models. Here is the full list from vendor pages, plus what the Suite needs.

FrSky says ETHOS runs on its TANDEM and TWIN series radios and on the Horus X10 and X12 series that have the built in ISRM RF module. The 2026 release notes also name the X20 PRO, X18RS, X14, X14RS, XERS, V15 and VX10. No radio from another brand is listed, and FrSky Suite runs on Windows and macOS with no published minimum versions.

Which radios run FrSky ETHOS

Which radios run FrSky ETHOS is answered in one line of FrSky's FAQ: the Horus X10 and X12 series with the built in ISRM RF module, and the TANDEM and TWIN series. That is the only answered question on the FAQ page. The release notes and the wiki name individual models, which fills in the picture.

Older FrSky radios such as the X9D or QX7 are not on any ETHOS list. They belong to the EdgeTX world, which our ETHOS vs EdgeTX comparison covers.

How storage differs between models

The wiki splits ETHOS radios into three storage layouts, which matters when you back up or flash by hand. The X20, X20S, X10E and ISRM Horus radios keep system bitmaps on a flash drive and everything else on the SD card. Older Horus systems use only the SD card. The X18 TANDEM keeps models, audio, logs and scripts on an internal NAND drive, with the SD card optional.

During a manual flash, firmware.bin goes to the root of the SD card on most models and to the root of the NAND drive on the X18. The steps to update the firmware cover both the Suite route and this one.

RF modules and receivers

ETHOS radios carry an internal RF module and an external module bay, and FrSky states both can run together with 24 channels each. Release notes mention ACCST D16, ACCESS, TD and TW modes across the range, Multimodule sensor support, and mLRS with 32 channels in 26.2.0. Stabilized ARCHER Plus, TD and TW receivers are set up with the StabilizerConfig Lua script; original ARCHER and ACCST receivers use the built in Device Config.

Computer requirements for FrSky Suite

FrSky does not publish a system requirements page. What its downloads and guides show is this:

  • Windows: FrSky Suite 2.0.2 installer, 142 MB
  • macOS on Intel: x64 disk image, 199 MB
  • macOS on Apple silicon: arm64 disk image, 202 MB
  • No Linux Suite build is listed; the simulator wiki mentions Windows and Linux consoles
  • A USB C data cable, not a charge only cable
  • An internet connection for update checks and downloads
  • The bootloader tool, DfuSe Demo 3.0.6, is a Windows program

Minimum Windows and macOS versions are not stated anywhere on the vendor pages. The Suite download page has the current files.

Frequently asked questions

Does the FrSky X20 run ETHOS?

Yes. FrSky's wiki documents storage and flashing for the X20 and X20S, and the 26.2.0 release notes include fixes for the X20 PRO and X20 AW. The X20 belongs to the TANDEM series that the FAQ names.

Can I install ETHOS on an X9D or QX7?

FrSky's ETHOS pages do not list the X9D or QX7. Those radios appear on EdgeTX's supported list as community supported, with version 2.11 the last release for the X9D and the original QX7.

Does ETHOS run on the X10S Express?

FrSky's FAQ names the Horus X10 and X12 series with the built in ISRM RF module. The X10 Express is not named on FrSky's ETHOS pages.

What are the system requirements for FrSky Suite?

FrSky publishes builds for Windows and for macOS on Intel and Apple silicon, at 142 MB to 202 MB, but no minimum OS versions. You also need a USB C data cable and an internet connection for updates.

Does ETHOS work with ExpressLRS?

FrSky's ETHOS pages do not document ExpressLRS. The 26.2.0 release notes do mention mLRS with 32 channels and a function to inject CRSF frames in the simulator.
