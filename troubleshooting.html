ETHOS Suite not working? Fixes for common FrSky update and flashing errors

When ETHOS Suite is not working, the cause is usually a blocked installer, a missed update prompt, the wrong USB mode or a device that needs a different cable. These fixes come from FrSky's own guide and wiki.

Most ETHOS Suite problems have a fix in FrSky's update guide. Keep a blocked download, start the update from the Suite Settings tab if no prompt appears, run the Suite as administrator if it stalls, and set USB Mode Preselection to Not set if the radio never offers Ethos Suite mode. For Device not responding on an RB35, cut power back feed by removing the red wire from one end of the servo lead.

When ETHOS Suite is not working on your computer

If ETHOS Suite is not working, start with the computer side. FrSky's guide lists three problems and their fixes, and each one is quick to rule out. Make sure the file came from FrSky's own site; the Suite download page links there.

The Suite does not see the radio

The radio has to be in the right USB mode. When you plug it in, a USB mode window should appear on the transmitter; choose Ethos Suite. If the window never shows, a mode has been preselected: go to SYSTEM, General and set USB Mode Preselection to Not set, then reconnect.

Use a USB C cable that carries data. A charge only cable powers the radio but no drives or Suite connection appear. If drive windows open on the computer when you connect, you can close them; the Suite still works.

Receiver and sensor flashing errors

The full receiver procedure is in the guide to update ETHOS firmware.

  • Over the air flash never finds the receiver: it must be registered and bound to this radio, and you must power it up while the radio shows Waiting for receiver.
  • Wired flash does nothing: signal goes on the notched side of the radio's S.Port, power in the middle, ground on the other side. A reversed plug does no harm but will not work.
  • Receiver with programmable pins will not flash: a pin set to S.Port cannot be used; use the dedicated Upgrade pins.
  • Device not responding on an RB35 or other device with a built in BEC: power it through its own port and remove the red wire from one end of the male to male lead so power cannot back feed into the radio.
  • Sensors such as FLVS or GPS have no over the air option: flash them with the wired method.

A flash fails or the radio will not start

The wiki gives a manual route that does not need the Suite. Hold Enter while powering on until Bootloader appears, connect USB, and two drives open on the computer. Copy the firmware as firmware.bin to the root of the SD card, or the NAND drive on an X18, eject both drives and unplug. The radio shows a progress bar and deletes firmware.bin when done; power cycle it afterwards.

Release notes show this area is still being fixed: 26.1.2 addressed reports of radios shutting down during bootloader flashing, and 26.2.0 candidates speed up emergency recovery. Before any recovery attempt, keep your models safe as described on the page about how to back up ETHOS models.

Reporting a bug FrSky has not fixed

FrSky collects bugs as GitHub issues in the ETHOS Feedback Community repository. Update to the latest version first, search open and closed issues, and if yours is new, give the firmware version, what you expected, the steps to reproduce and a screenshot or video. FrSky says it may not reply to every issue. The official site also runs a support ticket system for problems that are not firmware bugs.

Frequently asked questions

Why does ETHOS Suite not detect my radio?

Usually the radio is not in Ethos Suite USB mode or the cable is charge only. Set SYSTEM, General, USB Mode Preselection to Not set, reconnect with a USB C data cable and choose Ethos Suite when asked.

Why does the Suite update stall on Windows?

FrSky's guide says to close the Suite, right click its icon and choose Run as administrator, then continue the update. If the installed version is very old, uninstall it and install the current one.

What does Device not responding mean when flashing?

The radio cannot talk to the device on the S.Port. Check the plug orientation and use the Upgrade pins on receivers with programmable pins; for an RB35 or similar device with a BEC, remove the red wire from one end of the lead.

How do I recover a radio after a failed flash?

Hold Enter while powering on to enter the bootloader, connect USB, copy firmware.bin to the SD card root (NAND on the X18), eject and unplug. The radio flashes the file and deletes it when finished.

Where can I get help from FrSky?

Bugs go to GitHub issues in the ETHOS Feedback Community repository, with your firmware version and steps to reproduce. Other questions can go through the support ticket system on ethos.frsky-rc.com.
