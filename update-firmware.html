Before you update FrSky ETHOS firmware

To update FrSky ETHOS firmware the vendor's way you need the desktop Suite, a USB C cable that carries data, and a charged radio. FrSky's comprehensive guide was written for ETHOS 1.6.x and RF 3.0.x with ETHOS Suite; FrSky Suite 2.x keeps the same jobs, though some labels may differ. If you have not installed it yet, get it from the Suite download page.

The guide treats the radio as four layers: the OS, the internal RF module, the receivers, and sensors and other peripherals. Update them in that order, and do not skip the backup.

  • Suite installed and current: it offers Go To Update when a new version exists
  • Radio powered on and connected by USB C
  • On the radio, USB mode set to Ethos Suite
  • Models backed up to a folder on the computer

Update the OS

The full backup procedure, and the manual copy for when the Suite is not available, is on the page about how to back up ETHOS models.

  1. ConnectLaunch the Suite, power on the radio and plug it in. Choose Ethos Suite in the USB mode window. If that window never appears, set SYSTEM, General, USB Mode Preselection to Not set.
  2. Check statusOpen the Radio Information tab. It lists every item that is out of date.
  3. Back upIn Model manager, pick a backup location with the folder icon and click BACK UP. Tick Audio if you use custom sounds; it is off by default.
  4. Choose the buildOpen the Ethos tab under Radio. Select the Stable branch and the latest version, then your display language and audio languages.
  5. WriteClick the download icon next to WRITE OUTDATED COMPONENTS. Wait for UPDATE SUCCESSFUL, then go back to Radio Information.

Flash the RF module

The RF module runs the link between transmitter and receiver and has its own firmware. When it shows Out of date, click Manage internal module or open the RF Module tab, choose the newest entry in the Module firmware list, and click FLASH MODULE. Afterwards, Radio Information should show everything current.

FrSky calls RF module and receiver firmware matched. Once the module moves to a new version, check every receiver you fly with and update those too, or the link may not work as expected.

Install or update Lua scripts

Stabilized receivers and some peripherals need Lua scripts. The Lua library tab shows a Remote library of available scripts and, on the left, the Radio scripts already installed. Click INSTALL under a script to put it on the radio. StabilizerConfig is the one for ARCHER Plus (AP), TANDEM (TD) and TWIN (TW) stabilized receivers; original ARCHER and ACCST receivers are configured through Device Config, SxR, built into the OS.

Update receivers and sensors

In Download center, open RECEIVERS, find your model and click DOWNLOAD. TD and TW downloads arrive as a zip with all firmware for that family. Unzip it and copy the files into a folder such as updates on the RADIO drive, which may appear as Removable Drive or USB Drive.

  1. Over the air (TD, TW and ACCESS receivers): the receiver must be registered and bound. Press SYS, open File Manager, select the file and choose FlashRX by int OTA. Power the receiver during Waiting for receiver, select it, confirm with ENTER.
  2. Wired: connect the receiver's S.Port to the radio's S.Port with the harness, with no other power on the receiver. Signal goes on the notched side, power in the middle. Select the file and choose Flash External Device, then confirm.
  3. Sensors such as FLVS or GPS have no over the air option; use the wired route. Receivers with programmable pins must use the dedicated Upgrade pins.

If an RB35 or another device with a built in BEC answers Device not responding, the troubleshooting page has the fix FrSky gives.

Manual flash without the Suite

The wiki also documents a manual route for the X20, X20S, X18, X10 and X12S. Hold Enter while powering on to reach Bootloader, connect USB, copy the firmware as firmware.bin to the root of the SD card (the NAND drive on the X18), copy new audio and bitmap files, eject both drives and unplug. A progress bar runs; when it ends, power cycle the radio. Back up models and radio.bin first. Check the supported radios list for where each model stores these files.

Frequently asked questions

How do I update ETHOS firmware?

Connect the radio to FrSky Suite in Ethos Suite USB mode, back up in Model manager, then on the Ethos tab choose the Stable branch and latest version and click WRITE OUTDATED COMPONENTS. Wait for UPDATE SUCCESSFUL before unplugging.

Do I need to update the RF module after ETHOS?

Check Radio Information after the OS update. If the RF module shows Out of date, flash it from the RF Module tab. FrSky says RF module and receiver firmware are matched, so update receivers afterwards too.

Can I update a receiver without removing it from the model?

Yes for TD, TW and ACCESS receivers that are registered and bound: use FlashRX by int OTA from the radio's File Manager. Other receivers and sensors are flashed through the S.Port with a cable.

Should I pick the Stable or another branch?

FrSky's guide tells you to select the Stable branch and its latest version. Release candidates on GitHub carry an early adopters label and are meant for people who will report bugs.

Can I update ETHOS without the Suite?

Yes. Hold Enter while powering on to enter the bootloader, connect USB, copy firmware.bin to the SD card root (NAND on the X18), eject and unplug. The radio flashes itself and deletes firmware.bin afterwards.

The USB mode window does not appear. What now?

On the radio, go to SYSTEM, General and set USB Mode Preselection to Not set. Reconnect the cable and the choice window should appear.
