Download FrSky Suite from FrSky's official ETHOS site or its GitHub releases: version 2.0.2 comes as a 142 MB Windows installer and 199 MB or 202 MB macOS disk images for Intel and Apple silicon. The Suite then fetches ETHOS firmware, RF module files and Lua scripts for your radio, so you rarely need to download firmware files by hand. FrSky publishes no price.

What you get from the ETHOS Suite download

The ETHOS Suite download gives you the desktop tool that FrSky's update guide is built around. With it you can see what is out of date on the radio, write new ETHOS firmware, flash the internal RF module, back up models, install Lua scripts and fetch firmware for receivers and sensors. FrSky Suite 2.0.2 adds a radio simulator, a log viewer with two Y axes and per channel minimum, maximum and average, a DFU flasher and a searchable FrSky product list with favourites.

The official site lists two generations side by side: ETHOS Suite 1.6.3 for Windows and macOS, and the newer FrSky Suite 2.x for Windows, macOS on Intel and macOS on Apple silicon. The 2.0.2 release on GitHub, dated 30 October, is the most recent. The firmware itself is published as GitHub releases, and the Suite reads from the same place.

Firmware versions and branches

The newest ETHOS release on GitHub on 7 November 2026 was 26.1.2, dated 10 September, with fixes for bootloader flashing, Bluetooth audio, FBUS telemetry and NAND errors on the X18RS, X14 and XERS. The next version, 26.2.0, was at its ninth release candidate, dated 6 November. FrSky labels these builds as being for early adopters.

Inside the Suite you choose a release branch and a version from drop down lists. FrSky's update guide tells you to pick the Stable branch and the latest version in it. Release candidates are for people willing to report bugs.

Install in five steps

  1. Download the right buildUse the button on this page to reach ethos.frsky-rc.com and pick the Windows installer, or the macOS image for Intel (x64) or Apple silicon (arm64).
  2. Allow the fileIf the browser blocks it, choose Keep and then Keep anyway. If Windows Defender stops the installer, click More info and then Run anyway. On a Mac, allow the app under System Settings, Security.
  3. Install and launchRun the installer, then open the Suite. When a newer version exists, a pop up offers Go To Update.
  4. Connect the radioPower on the transmitter and connect it with a USB C data cable. In the USB mode window on the radio, choose Ethos Suite. You can close any drive windows that open on the computer.
  5. Check and back upOpen Radio Information to see what is out of date, then make a backup in Model manager before writing anything.

What to do after install

Do the backup first: our page on how to back up ETHOS models covers the Model manager and the manual copy. Then follow the vendor order to update ETHOS firmware: the OS, then the RF module, then the receivers.

If the download is blocked, the update prompt never appears or the radio does not show up, the ETHOS troubleshooting page lists the fixes from FrSky's guide.

Frequently asked questions

Is the ETHOS Suite download free?

FrSky shows no price for ETHOS Suite or FrSky Suite. Both are offered as downloads on ethos.frsky-rc.com and in FrSky's GitHub releases. The site states no licence terms.

Is ETHOS Suite the same as FrSky Suite?

The official site lists ETHOS Suite 1.6.3 and FrSky Suite 2.x as separate downloads. FrSky Suite is the newer generation, with a simulator, log viewer and DFU flasher added. FrSky's update guide was written for ETHOS Suite, so some menu names may differ in 2.x.

Which Mac file should I download?

FrSky Suite 2.0.2 ships two macOS images: x64 for Intel Macs at 199 MB and arm64 for Apple silicon Macs at 202 MB. Pick the one that matches the chip shown in About This Mac.

Is there a Linux version of FrSky Suite?

The official site lists Suite builds for Windows and macOS only. FrSky's simulator wiki mentions running the simulator from a Windows or Linux console, but no Linux Suite installer is listed.

Do I need to download ETHOS firmware files by hand?

Usually not. The Suite reads the available versions and writes outdated components to the radio for you. The manual route, copying firmware.bin to the radio in bootloader mode, exists for cases where the Suite cannot be used.

Why does Windows warn me about the installer?

FrSky's guide notes that the browser and Windows Defender SmartScreen may block the file. The guide's fix is to choose Keep, then Keep anyway, and More info, then Run anyway, for a file downloaded from FrSky's own site.
