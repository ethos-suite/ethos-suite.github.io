ETHOS backup: how to save and restore FrSky models and radio settings

An ETHOS backup is a copy of your model files and radio.bin on a computer. FrSky Suite makes it with one button in Model manager; without the Suite you copy the folders over USB.

To back up ETHOS, open Model manager in FrSky Suite, choose a backup location with the folder icon and click BACK UP, ticking Audio if you use custom sounds. Without the Suite, connect the radio by USB and copy the models folder and radio.bin from the SD card, or the NAND drive on an X18, to your computer. FrSky's guide says never to skip this step before an update.

Why an ETHOS backup comes first

An ETHOS backup protects the hours that go into a model setup: mixes, flight modes, telemetry screens, trims and timers. FrSky's update guide marks the backup step as important and tells you not to skip it, and the wiki repeats the warning for the manual flash: copy model files and radio.bin to a computer before you write firmware.

Two kinds of data matter. Model files hold each aircraft. The radio.bin file holds system settings such as calibration and preferences. Custom audio is a third, optional item that the Suite leaves out unless you ask for it.

Back up with FrSky Suite

If you do not have the Suite yet, the FrSky Suite download page lists the Windows and macOS builds.

  1. ConnectLaunch the Suite, power on the radio, connect a USB C data cable and choose Ethos Suite as the USB mode.
  2. Open Model managerClick Model manager in the tabs on the left.
  3. Set the locationClick the folder icon and pick or create a folder, for example FrSky Backups inside Documents. It then shows as the Backup location.
  4. Run the backupClick BACK UP. In Select components you want to back up, tick Audio if you have custom sound files.
  5. Check the folderOpen the folder on the computer and confirm the files are there before you update anything.

Manual backup over USB

Every ETHOS radio exposes its storage as drives when connected over USB. The wiki documents where the files sit, and the layout depends on the radio.

RadioWhere models and radio.bin live
X20, X20S, X10E, X10 ISRM, X12 ISRMSD card: models, radio.bin, audio, logs, scripts
Horus radiosSD card only, including bitmaps
X18 TANDEMNAND drive; SD card is optional

Copy the whole models folder and radio.bin to your computer. Add audio, scripts and bitmaps/models if you have changed them. Logs and screenshots are worth keeping if you want the flight history.

Restoring models

FrSky's guide covers making the backup but does not describe a restore button. Because the wiki documents where each file lives, putting a setup back is a copy in the other direction: connect the radio, copy the saved models folder and radio.bin back to the same place on the same drive, then eject and restart the radio.

Restore onto the same OS version the backup came from where you can, or onto a newer one. If a model behaves oddly after a restore, check the ETHOS troubleshooting notes and FrSky's GitHub issues for the version you are on.

When to back up

Once the backup is safe, continue with the steps to update ETHOS firmware.

  • Before every OS update and every RF module flash
  • Before a manual bootloader flash, which writes firmware.bin to the same card
  • After setting up a new model or changing mixes
  • Before formatting or replacing the SD card

Frequently asked questions

How do I back up models in ETHOS?

In FrSky Suite, open Model manager, set a backup location with the folder icon and click BACK UP. Without the Suite, copy the models folder and radio.bin from the radio's SD card, or NAND drive on an X18, over USB.

What is radio.bin in ETHOS?

FrSky's wiki describes radio.bin as the file holding the radio's system settings. It sits next to the models folder on the SD card, or on the NAND drive on the X18, and should be backed up with your models.

Does the Suite back up audio files?

Only if you ask. In the Select components you want to back up window, Audio is off by default; tick it to include custom sound files.

Where are ETHOS models stored?

In a models folder with one subfolder per model. On the X20, X10 and X12 families it is on the SD card; on the X18 it is on the internal NAND drive.

Can I restore an ETHOS backup to another radio?

FrSky does not document moving models between radio types. File locations differ between the X18 and other models, so check the destination radio's storage layout before copying.
